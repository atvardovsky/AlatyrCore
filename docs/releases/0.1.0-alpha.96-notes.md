  each ancestor scope. Artifact paths retain their own containment boundary.

  separate worker validation from primary review without requiring a full tree.

  supported runtimes. Touched enum checks validate types before membership.

  Every generated descriptor is inspected before comparison or sparse writes,
  including equal-byte symlinks. Planner and checker share budget arithmetic
  without conflating their measurement scopes. Compact plans retain exact
  missing paths and explicit overflow counts.
- Analysis/planning no longer persist relationship or package records.

  finalization after global reconciliation. Verify cannot authorize repairs.

only activated expanded flows gain phase/milestone guidance. Mandatory safety
checks have bounded local overhead, not a claimed latency or billing saving.
