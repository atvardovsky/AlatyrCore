# Bounded Cooperation

Framework `0.1.0-alpha.97`, adapter schema `79`, templates `92`.

## Changes

- Source minimum-work plans retain candidates beyond simultaneous capacity.
  Explicit selection is partitioned into policy/runtime-bounded waves, while
  default selection, total delegates, root children and cumulative context
  limits remain unchanged. Planning never launches workers.
- Prospective `session-presence status --scope` compares bounded scope without
  registration. `cooperation-preflight` composes existing presence and declared
  test-resource planning; no commands run and no new coordination store exists.
- The result preparer optionally derives `handoff.json` through `--compact` or
  `--metrics`, keeping the default preparation path unchanged.
  Node-update candidates remain incomplete and review-required. Explicit
  optional finite timing/rework observations cannot influence acceptance.
- Nested change flows distinguish initialization, workstream execution,
  reconciliation and sole-owner finalization. Companion decisions precede
  finalization; final-result binding validation remains required afterward.

## Target Update

Use the existing target-aware update lifecycle. Preserve local policy,
project-owned facts, active work, explicit opt-outs and historical evidence.
Reconcile the installed delegate and changed flow guidance rather than blindly
overwriting target facts. The added delegate operation is read-only.

Canonical result, execution-tree and presence record schemas are unchanged.
Adapter schema advancement records the installed delegate/flow contract update;
old evidence is not promoted or rewritten. Handoffs are optional source-tool
drafts, not a new acceptance format.

## Boundaries

Presence is advisory, local to one Git common directory and dependent on
participant reporting. Whole-resource identities conservatively ignore
namespace separation. Timings are observations, not billable-token evidence or
proof of measured product-wide improvement. No remote target update, release
tag or deployment is implied by this source checkpoint.
