# Alatyr Release Migration Report

This reviewed report compares the nearest reachable tagged source baseline
`v0.1.0-alpha.3` with the source tree prepared for `0.1.0-alpha.13`.
Migration reports for intervening `0.1.0-alpha.4` through
`0.1.0-alpha.12` remain part of the evidence chain. This report is source
evidence, not approval to modify a target repository.

Report ID: `alatyr-0.1.0-alpha.13`
Prepared by: `AlatyrCore maintainers`
Prepared at: `2026-08-20`

## Adapter Contract Impact

- Router schema 5 replaces the routine multi-file bootstrap with a generated
  `.ai/assistant/bootstrap-index.json` and loads focused gate fragments after
  task classification.
- Adapter schema 12 records the bootstrap and gate indexes while allowing
  approval surfaces to remain absent when the selected support profile and
  enabled modules do not require them.
- Target template version 13 adds the generated bootstrap index, gate index and
  fragments, capability-selected scaffolding, module-gated validation, and
  delta-first upgrade routing.
- The core scaffold is intentionally smaller. Optional module files are added
  through dependency-closed capability selection and are not enabled merely
  because files are present.
- Upgrade planning now emits `upgrade-impact.json`; full framework-corpus
  loading remains an explicit response to an unresolved dependency, conflict,
  missing migration fact, or requested full audit.

## Residual Risks

- Generated bootstrap indexes can become stale when a target bypasses the
  renderer; target validation detects deterministic drift but does not repair
  project facts automatically.
- Capability selection proves structural dependency closure, not that a module
  is appropriate for a project or that its project-owned policy is complete.
- Static context-word measurements approximate prompt size and are not billing,
  latency, or semantic-quality evidence.
- Native macOS and Windows behavior remains CI evidence after push.
- Historical releases after `v0.1.0-alpha.3` have migration reports but no
  reachable tags, so their evidence remains weaker than a tag per release.
