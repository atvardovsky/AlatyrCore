# Current Task Disposition And Evidence Delivery

Version: `0.1.0-alpha.102`; adapter schema `84`; target templates `97`.

Named-task health resolves the registered model/closure instead of scanning
historical reports. It keeps provisional finalization, publication, control
adoption and exercised canonical repair checks distinct. Narrative reports
remain historical observations; keep links in current records, not digest-bound
historical bytes.

Optional schema-6 `execution_dependencies` explicitly covers existing proof
obligations. A bounded shared resolver rejects missing/duplicate IDs, cycles
and settled work with unmet prerequisites. The projection preserves adopted
dependencies; default models do not gain a field. Readiness remains declared,
never permission, semantic truth or acceptance.

During already-selected consistency routing, exact selected document paths
also select source-bound stale-document warnings. The review still checks
finding identities, canonical owners and input digests. Candidate relationships
remain non-authoritative; warning review inputs never trigger recursive lookup.

## Impact And Compatibility

- Default health does not load the optional task view. No extra runner or
  historical-report scan is introduced; canonical validation stays unchanged.
- Current-task reporting reuses canonical registered repair-check observations.
  Installed templates alone cannot establish adoption or exercised evidence.
- Existing schema-6 models remain valid without dependency mappings. Older
  closed schema-4/5 witnesses remain historical, not newly accepted evidence.
- Update the installed delegate and adapted health/help/update instructions
  together. Adopting dependency mappings or repair review remains target-owned.
- No target repositories, application code, test timing, runtime, financial
  policy or authority were changed. No measured token-billing or project-speed
  improvement is claimed. Structured checks cannot establish causal truth.

Validation details are recorded in the companion migration report after checks.
