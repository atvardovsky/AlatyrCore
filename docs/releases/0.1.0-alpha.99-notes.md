# Field-Audit Closure

Source checkpoint: `0.1.0-alpha.99`; adapter schema `81`; templates `94`.
No rule IDs are added or removed. Existing canonical owners retain authority.

## Changes

- Every explicit registry owner needs a declaration-equivalent canonical binding
  on its referenced fact node. Derived bindings and coverage labels do not waive
  that duty. Bracketed literal paths route exactly, not as accidental globs.
- Canonical testing policy may select up to 16 additional Markdown templates.
  They use the existing structured timing/RED/coverage binding, with a 128 KiB
  file ceiling. Nothing executes commands or overrides manual-review-first.
- Problem-model schema 6 classifies each restoring delta as settled correction,
  incident repair or reviewed non-defect restoration. Source findings, accepted
  invariants and required restoration proofs remain linked. Frozen schemas 4/5
  remain historical; projection schema 4 is unchanged.
- Optional relationship-candidate schema 2 carries digest-bound stale-document
  reviews. Only selected endpoints deliver warnings. Candidates never enter the
  accepted impact closure, and stale review inputs require revalidation.
- Planning separates index discovery from leaf hydration. All structural and
  child-index integrity checks remain; full catalog acceptance is unchanged.
  Overflow stays blocked and proposes decomposition without dropping owners.

## Required Migration

Reconcile registry/map bindings and additional testing-template selection from
canonical project evidence. Upgrade active models and their projections
together; preserve old closed witnesses. Use original finding identities rather
than inventing one incident family for unrelated settled corrections. Recheck
context branches and ancestor digests. No automatic custom-checker replacement.
Bind selected-task completion to an explicit comparison base so unavailable
review history cannot be treated as an absent requirement. Health-only checks
do not need an invented task or completion binding.

## Proof Limits

Structured checks establish bindings, coverage and freshness, not domain truth,
reviewer authenticity, actual command semantics or assistant obedience. Private
ignored history cannot be reconstructed after external overwrites; publication
transactions protect retained obligations and durable witnesses preserve
available history. No product runtime, deployment or target tests are performed
by this source change. Performance evidence measures local I/O, not billed
tokens or universal wall-clock benefit.
