# Support Generation Gate

- The artifact has one canonical generator-policy owner.
- Inputs, outputs, dependencies, mode, and validation are explicit.
- The generation index matches the canonical registry.
- Deterministic execution uses staged output and a current plan digest.
- Assistant-proposed and owner-maintained artifacts remain review work.
- Current-scope modification authorization is present before applying output.
- Protected output remains inside an explicit approval scope.
- Generated output is validated before support state is refreshed.
- No relationship candidate was promoted automatically.
