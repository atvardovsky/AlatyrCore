# Semantic Integrity Gate

Canonical owner: `ALATYR-INTEGRITY-001`.

- Name each changed fact and its canonical owner.
- For business changes, retain per-rule before/after behavior and exact accepted
  authority; proposed or inferred restrictions cannot authorize themselves.
- For repairs, retain the source-derived original case before choosing a fix.
  Green implementation tests do not close an unverified original complaint.
- Re-derive scope, identity, ownership, lifecycle, persistence, caller, and
  dependency invariants that apply.
- Reconcile review items sharing a fact or contract and choose one coherent
  repair set.
- Traverse the enabled consistency map, or perform a compact manual impact
  closure across code, tests, docs, diagrams, gates, prompts, skills, and
  bridges.
- Record the documentation gate's Project Contour Sync Decision with checked
  owners, affected surfaces, evidence, and a fact-specific reason when no
  project-owned documentation update is required.
- Activate approval and security gates before protected semantic changes.
