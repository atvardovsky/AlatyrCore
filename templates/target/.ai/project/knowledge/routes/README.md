# Project Knowledge Route Shards

Store target-owned route shards here after a reviewed knowledge promotion.
Use stable project-area or dependency-domain shard boundaries and register each
shard in `.ai/project/knowledge/index.json`.

Each entry is a compact derived pointer to a canonical project source. Keep
summaries within the index policy and keep complete explanations in their
canonical owners.

Do not create a shard from unreviewed assistant conclusions. Use
`.ai/assistant/templates/project-knowledge-route-shard.json` as the authoring
shape and validate the result before registering it.
