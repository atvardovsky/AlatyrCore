# Target Skills

Add target repository skills here only when a recurring task has distinct
context, gates, rejection criteria, or references.

Skills must point to canonical target `.ai/assistant/flows/*.flow.md` files
instead of duplicating full workflow policy.

<!-- alatyr:scaffold-fragment {"requires_paths":[".ai/assistant/flows/skill-adaptation.flow.md",".ai/assistant/skills/example/SKILL.md"]} -->
Imported or third-party skills must be adapted through the target
`.ai/assistant/flows/skill-adaptation.flow.md` before becoming canonical.
Use `.ai/assistant/skills/example/SKILL.md` as the placeholder pattern for an
adapted canonical skill.
